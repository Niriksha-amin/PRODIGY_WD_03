# PRODIGY_WD_03
Tic-Tac-Toe Web Application
This project is a responsive Tic-Tac-Toe Web Application developed using HTML, CSS, and JavaScript. It allows users to play the classic two-player game directly in the browser with an interactive and visually appealing interface. The application tracks game progress, checks winning conditions automatically, and works smoothly across mobile, tablet, and desktop devices.

Features:
• Interactive Tic-Tac-Toe game board
• Two-player gameplay (Player X vs Player O)
• Automatic win and draw detection
• Game status display (turn & result)
• Reset / New Game button
• Responsive design for all screen sizes
• Built using pure HTML, CSS, and JavaScript

Technologies Used*
• HTML5
• CSS3
• JavaScript


Project Objective:
The objective of this project is to build a fun and user-friendly browser game while strengthening core web development skills such as DOM manipulation, game logic implementation, and responsive UI design.

How It Works:
Players take turns clicking on the grid cells.
The application places X or O based on the current player.
After each move, JavaScript checks for winning combinations or a draw.
When a player wins or the match ends in a draw, the result is displayed.
The Reset button allows users to start a new game anytime.

Learning Outcomes
• Implementing game logic using JavaScript
• DOM manipulation and event handling
• Working with arrays and conditional statements
• Building interactive and responsive web applications
• Improving problem-solving and UI design skills
